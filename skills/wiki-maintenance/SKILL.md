# wiki-maintenance

Run one proposal-only, non-authoritative Wiki maintenance operation while keeping Note/candidate reads and semantic
judgment outside the coordinator context. Audit produces a versioned metadata-only local report;
candidate consolidation produces a separate metadata-only proposal report. Neither changes Notes,
journals, Git, readiness, task contracts, or publication state.
