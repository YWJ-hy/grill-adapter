## grill-adapter stage router (grill / Claude Code)

Generated by grill-adapter. This marker opts the project into a thin convention-only router.

### Activation gate:
- This router is inert unless the matching grill stage is explicitly invoked.
- Do not infer a stage from an ordinary request.
- When no matching stage is active, do not route adapter work.
- During a matching active stage, invoke every listed entry skill at its row's stated workflow moment; the route is mandatory, not advisory. Do not invoke a later-moment route early.
- An explicit adapter-skill invocation remains available outside a grill stage.

### Stage routing

| Workflow moment | Entry skill | Purpose |
|---|---|---|
| /grill-with-docs | /grill-adapter:wiki-research | Disclose relevant Wiki context. |
| /to-spec | /grill-adapter:source-truth-check | Verify source-of-truth policy for the spec. |
| /to-tickets | /grill-adapter:wiki-research, /grill-adapter:source-truth-check | Carry selected context and verify the plan. |
| /implement | /grill-adapter:wiki-readiness | Establish one task before code changes. |
| /code-review (before reviewers) | /grill-adapter:wiki-readiness | Prepare reviewer context. |
| /code-review (after accepted review) | /grill-adapter:update-wiki | Capture durable knowledge. |
| /diagnosing-bugs (after evidence narrows the cause) | /grill-adapter:wiki-research | Disclose targeted Wiki context. |
| /diagnosing-bugs (after a verified fix) | /grill-adapter:break-loop | Run the debugging retrospective. |

### Cross-stage entries

| Workflow moment | Entry skill | Purpose |
|---|---|---|
| Any stage with a durable candidate | /grill-adapter:candidate-journal | Record it for post-review Capture instead of writing Wiki state directly. |
| Explicit knowledge upkeep | /grill-adapter:wiki-maintenance | Run an audit or consolidation only when explicitly requested. |

### Boundaries

- Each entry skill owns its detailed state machine, permissions, failures, and recovery.
- The router never patches host skills and never carries a plugin installation path.
- **Roster boundary:** For local scratch tickets use the NN filename prefix; for a real tracker use its issue number. Preserve verbatim ticket text.
- **State boundary:** Workflow state stays local under `.grill-adapter/context/`; do not commit it or bypass an entry skill's documented workflow when changing it. `.grill-adapter/settings.json` is project configuration.
