## grill-adapter stage router (plain / Codex)

Generated by grill-adapter. This marker opts the project into a thin convention-only router.

### Activation gate:
- Plain workflows do not infer a host stage.
- When an explicit workflow moment matches a row, invoke every listed entry skill at that moment; the route is mandatory, not advisory.

### Stage routing

| Workflow moment | Entry skill | Purpose |
|---|---|---|
| Before an approach | $grill-adapter:wiki-research | Disclose relevant Wiki context. |
| Before finalizing a spec | $grill-adapter:source-truth-check | Verify source-of-truth policy for the spec. |
| Implementation plan | $grill-adapter:wiki-research, $grill-adapter:source-truth-check | Carry selected context and verify source-of-truth policy for the plan. |
| Before code changes | $grill-adapter:wiki-readiness | Establish one task before implementation. |
| Before reviewers | $grill-adapter:wiki-readiness | Prepare the reviewer context. |
| Accepted review | $grill-adapter:update-wiki | Capture durable knowledge. |
| After evidence narrows the debugging cause | $grill-adapter:wiki-research | Disclose targeted Wiki context. |
| After a verified debugging fix | $grill-adapter:break-loop | Run the debugging retrospective. |

### Cross-stage entries

| Workflow moment | Entry skill | Purpose |
|---|---|---|
| Any stage with a durable candidate | $grill-adapter:candidate-journal | Record it for post-review Capture instead of writing Wiki state directly. |
| Explicit knowledge upkeep | $grill-adapter:wiki-maintenance | Run an audit or consolidation only when explicitly requested. |

### Boundaries

- Each entry skill owns its detailed state machine, permissions, failures, and recovery.
- The router never patches host skills and never carries a plugin installation path.
- **Roster boundary:** Use the user-confirmed task source, one stable task id, and verbatim full task text.
- **State boundary:** Workflow state stays local under `.grill-adapter/context/`; do not commit it or bypass an entry skill's documented workflow when changing it. `.grill-adapter/settings.json` is project configuration.
